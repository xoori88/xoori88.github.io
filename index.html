# SEO Portfolio — Deployment & Customization Guide Your portfolio is a single, dependency-free `index.html` file. No build step, no framework — it will deploy anywhere in under 5 minutes. --- ## 1. Customize before publishing (15-minute checklist) Open `index.html` in any editor and use Find & Replace: | Find | Replace with | |---|---| | `Orielle Jeffrey` | Your actual name (appears in title, schema, hero, footer) | | `ojseoprofessional.com` | Your live URL (e.g. `yourname.github.io` or custom domain) | | `oriellejeffrey@gmail.com` | Your real email | | `Orielle Jeffrey` | Your LinkedIn username | | `` | Your GitHub username | | `Port of Spain, Trinidad & Tobago` | Your location | |`OJ` (the favicon initials in the hero SERP card) | Your initials | | `oriellejwffrey.seo` (nav logo) | Your name/brand | **Also:** 1. **Resume** — drop your resume file next to `index.html` named `resume.pdf` (both download buttons already point to it). 2. **Certificate link** — in the Credentials section, replace the `View certificate →` View HubSpot SEO Certificate → 3. **Screenshots** — every placeholder shows a suggested filename like `img/remarc-gsc.png`. Create an `img/` folder, add your screenshots with those names, then replace each placeholder `
…
` with ``. Keep the descriptive `alt` text — recruiters *and* Google read it. 4. **OG image** — create a 1200×630 image named `og-image.jpg` (Canva works) and put it next to `index.html` so link previews look sharp on LinkedIn. 5. **Contact form** — sign up free at [formspree.io](https://formspree.io), create a form, and replace `YOUR_FORM_ID` in the form's `action` attribute. Messages will arrive in your inbox. (Until then the form won't send.) 6. **Testimonials** — the three cards are labelled "replace me"; swap in real quotes when you have them, or delete the section. --- ## 2. Deploy — pick ONE option ### Option A: GitHub Pages (free, gives you `username.github.io`) 1. Create a GitHub account, then create a new **public** repository named exactly: `your-username.github.io` (use your real username). 2. Upload `index.html`, `resume.pdf`, `og-image.jpg`, and the `img/` folder (repo page → **Add file → Upload files → Commit**). 3. Go to **Settings → Pages** — confirm Source is `main` branch, root. 4. Wait ~2 minutes. Your live URL: **https://your-username.github.io** > Bonus for recruiters: the repo itself shows you can use GitHub. ### Option B: Netlify (fastest — 60 seconds, no account needed to test) 1. Go to [app.netlify.com/drop](https://app.netlify.com/drop). 2. Drag the whole project folder onto the page. 3. You instantly get a URL like `https://something.netlify.app`. 4. Create a free account to keep it, and rename the site: **Site settings → Change site name** → `yourname-seo.netlify.app`. ### Option C: Vercel 1. Sign up at [vercel.com](https://vercel.com) (GitHub login is easiest). 2. Either **import your GitHub repo** (auto-deploys on every push), or install the CLI: `npm i -g vercel`, then run `vercel` inside the folder. 3. You get `https://yourproject.vercel.app`. --- ## 3. After it's live — SEO your own portfolio (do this, it's a talking point) 1. **Update the canonical + OG URLs** in `index.html` to your final live URL. 2. **Google Search Console** — add your site as a property, verify (HTML tag method is easiest), and use **URL Inspection → Request Indexing**. 3. **Validate your schema** at [validator.schema.org](https://validator.schema.org) and check rich-result eligibility at Google's Rich Results Test. 4. **Run Lighthouse** (Chrome DevTools → Lighthouse) — this single-file site should score 95+ on Performance and SEO; screenshot it for LinkedIn. 5. **Add the URL everywhere** — LinkedIn featured section, resume header, email signature. > In interviews: "I applied my own SEO process to my portfolio — schema, GSC, Core Web Vitals" is a great line, and now it's true. --- ## 4. Custom domain (optional, ~US$10/yr) Buy `yourname.com` at Namecheap/Cloudflare, then: - **GitHub Pages:** Settings → Pages → Custom domain, and add the 4 GitHub A records + CNAME at your registrar. - **Netlify/Vercel:** Domains → Add domain, follow the DNS instructions shown. Both give you free HTTPS automatically. --- ## File structure when finished ``` your-portfolio/ ├── index.html ← the entire website ├── resume.pdf ← your resume ├── og-image.jpg ← social sharing preview (1200×630) └── img/ ← your project screenshots ├── remarc-home.png ├── remarc-gsc.png ├── wahmeh-blog1.png ├── knoli-keywords.png └── ...
